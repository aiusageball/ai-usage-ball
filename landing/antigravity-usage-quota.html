How to check your Antigravity usage quota before the next agent task

Antigravity can expose more than one kind of usage state. The official quota panel is the detailed check; a persistent desktop view helps you notice the state before starting work.

Updated September 1, 2026 · For Antigravity users on macOS

Open the official Model Quotas panel

In the Antigravity CLI, type /usage and press Enter. The command has a /quota alias. The official documentation says the panel refreshes model configuration and quota status when it opens.

/usage

Use the official panel when you need the account-level detail. It can show a breakdown of remaining requests or tokens for supported models, depending on what your account and plan expose.

Read model quota separately from credits

Antigravity's usage experience can include baseline model quotas, a statusline indicator, low-quota warnings, and AI credits. These are related but not interchangeable. A model can be available while a credit balance is low, or a credit option can be unavailable for the current account.

Do not publish a fixed quota table as if it were permanent. Entitlements, model availability, and limits depend on the signed-in account and can change. Link to the official usage and plans documentation when explaining current behavior.

Why quota can change faster than expected

Agent work is not always a fixed one-request unit. The model, reasoning mode, tools, context, and task complexity can affect how much work is consumed. Check the model-level status before a long build, browser task, or multi-step refactor.

If the panel looks stale, close it and open it again to trigger the documented refresh path. Also verify that the CLI and desktop or IDE client are signed in to the same account if you are comparing screens.

A simple workflow for fewer surprises

  1. Check before the long task. Open /usage or /quota and note the relevant model.
  2. Match the model to the work. Use a lighter or faster option when it is sufficient.
  3. Leave a margin. Do not start a long agent task when the relevant quota is already near its warning threshold.
  4. Verify after a reset or plan change. Reopen the panel instead of relying on a previous percentage.
