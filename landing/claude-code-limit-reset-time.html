When does Claude Code usage reset?

The reset time depends on how you authenticate and which plan you use. Here is how to find the current answer for your account without confusing a new session with a new allowance.

Updated September 1, 2026 · For Claude Code users on macOS

Start with the account-specific status

In an active Claude Code session, run /usage to see the plan usage limits and current rate-limit status. You can also review the usage area in Claude Settings. The exact allowance and reset information can change by plan, account, workspace, and authentication method.

/usage

When the session reaches a limit, Claude may show a message with the relevant reset time. Treat that message and the current account usage view as more reliable than a fixed number copied from an old post.

Session limits and weekly limits are different

Many individual Claude plans have a session-based usage window, and paid plans can also have a weekly limit. Anthropic describes the session allowance as resetting on a rolling window for supported plans, while a weekly limit can have its own account-assigned reset time. Your account may show more than one limit at once.

A new conversation does not equal a reset. Starting a fresh Claude Code session can give you a cleaner context, but it cannot refresh an account-side usage allowance.

Authentication changes the answer

Anthropic distinguishes Claude Code sessions authenticated with a Claude subscription from sessions using an API key. Subscription usage is governed by the plan's included limits; API-key usage is pay-as-you-go and is shown as cost rather than a single subscription quota. If the status looks unexpected, check whether ANTHROPIC_API_KEY is set in the environment and which account the session used.

Claude, Claude Code, and Claude Desktop usage can share a plan allowance for supported subscription users. A long conversation in one surface can therefore affect what is available in another.

What to do before the reset

  • Save your current changes and note the reset shown by the account.
  • Use /context or /compact when the problem is conversation length rather than usage allowance.
  • Switch to a smaller task or a suitable lower-cost model when that still meets the goal.
  • Check whether your plan offers usage credits or another supported continuation option before enabling paid usage.

Keep the reset visible

Checking /usage is the right diagnostic step. A persistent desktop indicator helps with the next decision: whether to start a long task now, switch to another assistant, or wait until the reset.
